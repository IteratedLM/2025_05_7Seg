This is the code we used to make the images for 

Image, Word and Thought: A More Challenging Language Task for the Iterated Learning Model
Hyoyeon Lee, Seth Bullock, Conor Houghton
https://arxiv.org/abs/2601.02911

and the associated shorter paper accepted for EvoLang2026. 

This paper was originally written for ALIFE, which, inexplicably in our view, rejected it. The figures changed slightly for the EvoLang submission, mostly figure 7 was improved and we changed the names for the noise levels from noisy, very noisy
and super noisy to the more conventional noise 1, noise 2 and noise 3.
